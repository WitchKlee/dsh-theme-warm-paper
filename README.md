# 暖纸 · Warm Paper

> 安静、温柔、低饱和的手记风主题：米杏纸色、宋体书卷气、细微纸纹、砖红书脊与一枚当日日期戳。
> 为 DeepSeek Harness Web UI 而作，不修改宿主源码，只叠一层完整的主题 token。

## 设计要点

| 层 | 内容 | 实现 |
| --- | --- | --- |
| 色彩 | 米杏纸 `#F5EEE0`、深棕墨 `#3B2F25`、砖红 `#A24B3B`、灰绿 `#586D52` | `ctx.theme.overrideTokens()` 覆盖全部 `--dsw-alias-*`（浅/深两套） |
| 字体 | 正文与标题使用旧式衬线 + 宋体栈（Sitka / Palatino → 宋体 / 思源宋体 → SimSun） | 覆盖 `--dsw-font-family`：用户「正文字体」排最前，暖纸衬线栈始终垫后，无效字体名回落宋体 |
| 材质 | 180px 的极淡颗粒、左侧 2px 砖红书脊线、砖红选区 | 一张门控样式表（`html[data-warm-paper="on"]`） |
| 气泡 | 用户消息砖红 `#A24B3B` 底 + 米色 `#FBF6EB` 字，链接始终下划线 | 宿主没给气泡文字单独 token，用 `[class*="_bubble"]` 作用域补一条样式 |
| 悬停卡 | 侧栏会话/工作区的 HoverCard 改成纸色卡片、墨色文字 | 宿主原语把底色写死 `#2C2C2E`、文字写死白色，按 `_hoverContent` 定位覆盖 |
| 记录 | 输入框下方「● 2026 · 10 · 21」日期批注 | `conversation.composer.dock` 装饰槽 |

深色不是简单反相：它是「夜读纸」——暖褐纸面、米色墨字，砖红提亮为陶土色，灰绿提亮为灯下的苔色。
对比度按 WCAG 校准：正文约 11:1，三级文字约 5:1，砖红按钮与气泡上的米色字约 5.4:1。

## 设置界面

是一个独立的设置 tab，两个入口共享同一份状态：

- **设置 → 暖纸**（设置面板左侧一级 tab，排在「通用设置」和「模型」之间）
- **设置 → 插件 → 已安装 → 暖纸** 的 bundle 详情页（描述下方的配置区，
  即 `plugins.bundle.config` 槽，按包名 `dsh-theme-warm-paper` 挂载）

不再嵌入「通用设置」页。可以调：

| 选项 | 作用 |
| --- | --- |
| 启用暖纸主题 | 总开关；关掉立即回到宿主原样，其他选择保留 |
| 纸色 | 米杏 / 宣白 / 茶褐 三种纸底；只换背景类 token，不动文字与强调色 |
| 纸纹 | 无 / 轻 / 重 三档纸面颗粒 |
| 书脊线 | 左侧那条 2px 砖红订口线，可单独关掉 |
| 消息气泡 | 砖红 / 陶土 / 纸色 三种底色，砖红与陶土自动反白文字 |
| 正文宋体 | 关掉后正文回到宿主的无衬线字体 |
| 衬线字体 | 宋体 / 思源宋体 / 仿宋（中文家族偏好；宿主「正文字体」仍优先） |
| 正文字号 | 10–22px 步进器，与「通用设置 → 字号大小」是同一个宿主设置，两边同步 |
| 代码字号 | 10–16px 步进器，与「通用设置 → 代码字号」同步 |
| 终端字号 | 10–20px 步进器，作用于右侧边栏终端面板（需打开终端标签）；与「通用设置 → 终端字号」同步 |
| 侧栏字号 | 小 / 标准 / 大；覆盖左侧会话列表与导航的字号（宿主无此设置，由主题 CSS 覆盖） |
| 日期戳 | 完整 / 简 / 关；「简」只留月和日 |
| 恢复默认 | 回到出厂设置 |

页面顶部还有一块**实况预览**：纸底、宋体样字、用户气泡、日期戳都直接使用当前 token，改任何选项即时反映。

设置存在本机 `localStorage`（`dsh-theme-warm-paper.settings`），刷新后保留，换浏览器不跟随。
「正文字号 / 代码字号 / 终端字号」是例外：它们写的是宿主的主题偏好（与「通用设置」里的同名字号同一个值）。
宿主「正文字体」里填的字体永远排在最前；填了无效名字（例如数字）时回落到暖纸宋体，不会掉回系统无衬线。

## 安装

在 DSH 里由 `plugin_manager` 以本地目录安装（不要手写 profile 的 package.json）：

```text
plugin_manager({ action: "install_bundle", target: "<本目录绝对路径>" })
```

安装后 Client 半边随 HMR 生效；若宿主提示需重启，重启 DSH 后再看。

## 关闭 / 卸载

- 关闭：设置 → 插件 → 已安装 → 暖纸 → 详情页里的「启用暖纸主题」开关；
  或在同一列表里禁用该 bundle（卸载客户端模块，主题与日期戳一起撤走）。
- 卸载：`plugin_manager({ action: "remove_bundle", target: "dsh-theme-warm-paper" })`。

## 兼容性

- 需要支持 `ctx.theme.overrideTokens()` 的 DSH（0.2.x Client 契约）。
- 已验证：DSH Desktop 0.2.1-rc.2（2026-10-21），浅色 / 深色 / 跟随系统、设置页、日期戳均正常；完全退出后冷启动复验通过。
- 不 patch 宿主源码、不改宿主 CSS 文件；调色板全部走 `--dsw-alias-*` token。
- 唯一依赖的宿主类名是用户气泡的 CSS Modules 局部名（`<hash>_bubble`）与左侧栏的字号类（`<hash>_title` / `_meta` / `_time` 等），因为宿主没有给这两类文字单独的 token。
  宿主若改名，这两处会退回宿主原样式（气泡底色 + 墨字 / 侧栏原字号），其余部分不受影响。
- 若同时启用了其他主题插件，后注册的 token 层按 token 覆盖，建议只留一个主题。
